## Scope

One screen with who the person is and how much they can still send today.

**Key components**
- Identity block: display name, phone, initial avatar
- Account details: personal/business, trading market (business only), KYC state
- **Daily limit bar**: used vs limit, and what is left today

**Product rule (enforced)**: the limit and the usage come from `/me` only. The
app never adds up trades to guess usage (rule 5). While `/me` is unreachable the
screen says "Your profile is not connected yet.".

## Contract (`docs/api_contract.md`)

```
GET /api/v1/me        (needs login)
{
  "id": "<id>", "phone": "+<dial><number>", "displayName": "<name>",
  "accountType": "personal | business",
  "hubId": "<id>" (business only, optional),
  "kycStatus": "verified | pending | rejected",
  "limit": { "currency": "<code>", "dailyLimitMinor": <int>, "dailyUsedMinor": <int> }
}
```
- `limit.currency` must exist in `/config`; an unknown code is a broken response.
- `kycStatus` `not_started` is not sent by the server today; the app still has a
  label for it (`profile.kyc.notStarted`).
