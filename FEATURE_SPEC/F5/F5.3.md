### Step 7 - Error fixes, test-hang diagnosis & full verification (2026-11-06)
- Errors fixed: (1) `setLocale` -> `setLanguage` (language selector called a method that does not exist); (2) `main_shell_screen_test` expectation updated to `'Transaction history'` (Account tab is now a hub, not a placeholder); (3) PIN-gate test hang (below).
- **Test hang root cause**: `PinManager.ensureUnlocked` -> `FlutterSecureStorage.read` goes through `MethodChannel('plugins.it_nomads.com/flutter_secure_storage')`; under `testWidgets` the channel has **no responder**, so the returned future **never completes** (it does NOT throw `MissingPluginException`) -> `_visible` stays false, the spinner spins forever -> `pumpAndSettle` timeout. The try/catch fail-open in `_gate` therefore never fires.
- **Fix (test-side only)**: the plugin's own `@visibleForTesting` hook `FlutterSecureStorage.setMockInitialValues({})` in `main_shell_screen_test.dart` `setUp` - backs reads with an in-memory map; empty map -> no PIN -> gate opens instantly. No timeout hack or test-detection logic added to `lib/` (a timeout in `_gate` would weaken real-device security and mask genuine hangs).
- `GATE-DEBUG` debugPrint probes (added during diagnosis) removed from `main_shell_screen.dart`.
- Verified: `dart analyze lib/ test/` -> **No issues found** (6 info lints fixed); `flutter test` -> **169/169 all passing**; `flutter build web --release -t preview/main.dart` -> preview served HTTP 200 (port 8000).
